# homebrew-tap

```sh
brew tap armandrt/tap
brew trust armandrt/tap    # Homebrew 7 and later
brew install --cask claude-account-switcher
```

- [claude-account-switcher](https://github.com/armandrt/claude-account-switcher) — macOS menu bar app that shows every Claude Code account's quota and switches the live login in one click.
